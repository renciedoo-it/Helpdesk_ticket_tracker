# Helpdesk Ticket Tracker

A simple command-line ticket tracking system built in Python as part of my Python learning journey.

## Features

- Add new tickets with title and description
- View all tickets
- Search for a ticket by ID
- Close a ticket
- Input validation (blank fields, invalid IDs)
- Data persists between sessions using JSON file storage
- Built using Object-Oriented Programming (OOP) with a `Ticket` class

## Technologies Used

- Python 3
- JSON for data persistence

## How to Run

1. Clone this repository
2. Run the script:
python Ticket_tracker.py
3. Follow the on-screen menu to add, view, search, or close tickets

## What I Learned

This project helped me practice variables, loops, functions, dictionaries, error handling (try/except), input validation, file I/O with JSON, and Object-Oriented Programming (classes, methods, attributes).
